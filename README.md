# Current Spot – Support (English)

Welcome to the support page for **Current Spot** – the app for exchange electricity prices on iPhone, Apple Watch, iPad, Mac, and Wear OS.

## 🐛 Report a bug or ask a question

Please open an **[Issue](../../issues/new)** – I usually reply within 24 hours.

Helpful for a quick resolution:
- What happened, what did you expect?
- Device + version (e.g. "iPhone 15, App 1.0")
- A screenshot, if available
- You can share logs directly from the app (iPhone: **More → Share Logs**)
